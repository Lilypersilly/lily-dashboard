                    LILY DASHBOARD MODULE — USB DRIVES
================================================================================

File:      usb_drives.rs
Tab ID:    usb
Title:     USB Drives
Lifecycle: stateful
Hooks:     init

--------------------------------------------------------------------------------
1. SUMMARY
--------------------------------------------------------------------------------

A removable USB drive manager for Lily Dashboard. It lists connected USB flash
drives, external USB HDDs/SSDs, and removable SD cards (filtering out internal
system drives, loop devices, zram, optical drives, swap, and raw encrypted
crypto_LUKS headers).

Features:
  - Left-click an unmounted partition to mount it passwordlessly via udisksctl.
  - Left-click a mounted partition to open its folder in the default file
    manager and close the dashboard drawer.
  - Right-click any drive for a context menu to:
      * Mount / Unmount
      * Open in File Manager
      * Enable / Disable Auto-Mount (saved per partition UUID)
      * Copy Mount Path / Copy Device Path to the clipboard
      * Safely Eject (unmounts all partitions on the parent drive and powers it
        off)
  - Event-driven background auto-mounter (started via `init()`): listens to
    UDisks2/GVfs hotplug events via `gio::VolumeMonitor` (zero disk polling) and
    automatically mounts recognized UUIDs when plugged in or already connected
    at startup, without fighting manual unmounts.
  - Lists offline saved auto-mount drives so they can be forgotten/removed even
    when unplugged.

2. IMPORTS & DASHPENDENCIES
--------------------------------------------------------------------------------

External Dashpendencies (crates.io):
  - None. Uses only core crates already bundled with Lily Dashboard and the Rust
    standard library.

Core Crates & Imports Used:
  - `gtk4` (`Align`, `Box`, `Button`, `GestureClick`, `Label`, `Orientation`,
    `PolicyType`, `Popover`, `ScrolledWindow`, `prelude::*`):
      Builds the sidebar UI, drive cards, and right-click context menu.
  - `gtk4::gdk`:
      Writes the mount path or device path to the Wayland clipboard when the
      user clicks "Copy Mount Path" / "Copy Device Path".
  - `gtk4::gio`:
      Uses `gio::VolumeMonitor::get()` for event-driven USB connect, disconnect,
      mount, and unmount signals, and `gio::AppInfo::launch_default_for_uri` to
      open mounted drive folders in the default file manager.
  - `gtk4::glib`:
      Resolves the user config directory (`user_config_dir`), converts folder
      paths to `file://` URIs (`filename_to_uri`), and schedules GTK main-loop
      callbacks (`idle_add_local_once`, `timeout_add_local`,
      `timeout_add_local_once`, `ControlFlow`).
  - `serde` (`Serialize`, `Deserialize`):
      Serializes and deserializes saved auto-mount UUID entries.
  - `serde_json` (`Value`, `from_slice`, `from_str`, `to_string_pretty`):
      Parses `lsblk -J` JSON output and reads/writes the JSON config file.
  - `std` (`cell::{Cell, RefCell}`, `collections::{BTreeMap, HashSet}`, `fs`,
    `path::{Path, PathBuf}`, `process::Command`, `rc::Rc`,
    `sync::{Mutex, OnceLock, atomic::{AtomicBool, AtomicU64, Ordering}, mpsc}`,
    `time::Duration`, `thread::spawn`):
      Manages state, runs CLI commands on background threads so GTK never
      blocks, deduplicates concurrent hotplug events, and reads/writes config.
  - `crate::module_api` (`ModuleContext`, `ModuleHandle`):
      Standard module API (`popover_guard`, `close_drawer`, `on_show`).
  - `crate::config::bin_exists`:
      Checks whether `udisksctl` is installed in `PATH` to display a missing
      dependency warning if absent.
  - Unsafe code:
      None.


--------------------------------------------------------------------------------
3. FILESYSTEM ACCESS
--------------------------------------------------------------------------------

Directories Created (if missing):
  - `~/.config/lily-dashboard/` (via `glib::user_config_dir()` + `fs::create_dir_all`)

Files Read & Written:
  - `~/.config/lily-dashboard/usb_automount.json`
      Stores a JSON map (`automount_uuids`) of partition UUIDs to their display
      label and drive model. Read on startup/scan and written only when the user
      enables, disables, or removes an auto-mount entry.

Other Path References (not directly read or written by this module):
  - `/dev/<name>` fallback device paths derived from `lsblk` output, passed only
    to `udisksctl` or copied to the clipboard on user click.
  - Mounted USB directory paths reported by `lsblk`, passed only to the default
    file manager (`gio::AppInfo::launch_default_for_uri` / `xdg-open`) or copied
    to the clipboard on user click.


--------------------------------------------------------------------------------
4. COMMANDS & NETWORK
--------------------------------------------------------------------------------

Shell Binaries Invoked (`std::process::Command::new`):
  1. `lsblk -J -o NAME,PATH,LABEL,UUID,SIZE,MOUNTPOINT,FSTYPE,TRAN,RM,HOTPLUG,TYPE,MODEL`
       Read-only block device enumeration to detect connected USB/removable
       drives and their partitions.
  2. `udisksctl mount --no-user-interaction -b <dev_path>`
       Mounts a USB partition when clicked by the user or when a saved
       auto-mount UUID is plugged in.
  3. `udisksctl unmount --no-user-interaction -b <dev_path>`
       Unmounts a mounted USB partition when requested by the user or prior to
       safely ejecting the parent drive.
  4. `udisksctl power-off --no-user-interaction -b <parent_path>`
       Powers off the parent USB drive when the user clicks "Safely Eject
       (Power Off)".
  5. `notify-send -a "Lily Dashboard" <title> <body...>`
       Displays desktop notifications when a drive is auto-mounted ("USB
       Auto-Mounted") or safely ejected ("USB Safely Ejected").
  6. `xdg-open <mountpoint>`
       Fallback used to open a mounted USB folder only if `glib::filename_to_uri`
       fails.

Network Access:
  - None. This module makes zero network connections and contacts no URLs.
